# Side Mission 04 — Coffee House Margins

- **District:** College Street
- **Lead:** Nia Vale
- **Theme:** Creative community
- **Status:** Narrative design brief; not yet connected to the playable mission runtime.

## Premise
Notes tucked inside donated books reveal a decades-old reading circle that has lost touch.

## Mission beats
1. Trace three handwritten notes
2. visit the old meeting place
3. find former members
4. host a new reading circle.

## Player choice
Keep the original notes private or display copies with permission.

## Implementation notes
- Keep this mission optional and independent of the main campaign.
- Grant any future reward only once, using a persistent mission-completion flag.
- Do not overwrite existing save fields or change the current save key.
- Keep dialogue respectful and avoid requiring the player to share real personal information.
- Future runtime work should add a map marker, objective chain, journal entry and completion test together.
