# Side Mission — The Lake Clean-up Ledger

- **District:** South Kolkata Lakes
- **Lead:** Nia Vale
- **Theme:** Environmental care
- **Status:** Narrative design brief; not yet connected to the playable mission runtime.

## Premise
A volunteer group wants to record its lakeside clean-up work consistently without turning the activity into a competition.

## Mission beats
1. Meet the team
2. agree on simple categories
3. organise the ledger
4. share a monthly community update.

## Player choice
Publish totals only or include short volunteer reflections.

## Implementation notes
- Keep this mission optional and independent of the main campaign.
- Grant future rewards only once using a persistent completion flag.
- Preserve existing save fields and the current save key.
- Future runtime work should add a map marker, objective chain, journal entry and completion test together.
