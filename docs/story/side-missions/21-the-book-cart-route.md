# Side Mission — The Book Cart Route

- **District:** College Street
- **Lead:** Jax Mercer
- **Theme:** Access to learning
- **Status:** Narrative design brief; not yet connected to the playable mission runtime.

## Premise
A volunteer book cart needs a route that reaches more students without blocking busy pavements.

## Mission beats
1. Meet the cart team
2. map quieter stops
3. test a timed route
4. publish the weekly schedule.

## Player choice
Visit fewer stops for longer or more stops for shorter visits.

## Implementation notes
- Keep this mission optional and independent of the main campaign.
- Grant future rewards only once using a persistent completion flag.
- Preserve existing save fields and the current save key.
- Future runtime work should add a map marker, objective chain, journal entry and completion test together.
