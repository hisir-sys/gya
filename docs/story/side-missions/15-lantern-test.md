# Side Mission 15 — Lantern Test

- **District:** Kumartuli
- **Lead:** Jax Mercer
- **Theme:** Festival preparation
- **Status:** Narrative design brief; not yet connected to the playable mission runtime.

## Premise
A workshop's lantern prototypes need a safe public display plan that does not obstruct the narrow lane.

## Mission beats
1. Meet the artisans
2. measure the display area
3. plan a pedestrian route
4. host a small preview.

## Player choice
Display every prototype or curate a smaller set with more space.
