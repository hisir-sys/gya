# Side Mission — The Ghat Garden

- **District:** Hooghly riverfront
- **Lead:** Eli Cross
- **Theme:** Shared space
- **Status:** Narrative design brief; not yet connected to the playable mission runtime.

## Premise
Residents are trying to maintain a small planter area near a public riverside rest point.

## Mission beats
1. Meet the caretakers
2. identify suitable plants
3. agree on a watering rota
4. mark a care guide.

## Player choice
Plant seasonal flowers or hardy native greenery.

## Implementation notes
- Keep this mission optional and independent of the main campaign.
- Grant future rewards only once using a persistent completion flag.
- Preserve existing save fields and the current save key.
- Future runtime work should add a map marker, objective chain, journal entry and completion test together.
