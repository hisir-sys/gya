# Side Mission — The Seed Library

- **District:** Eco Park
- **Lead:** Nia Vale
- **Theme:** Shared resources
- **Status:** Narrative design brief; not yet connected to the playable mission runtime.

## Premise
A volunteer group wants to start a small seed exchange with clear notes about origin and care.

## Mission beats
1. Meet the gardeners
2. catalogue donated seeds
3. write care cards
4. open the exchange shelf.

## Player choice
Limit the first exchange to local varieties or include labelled donations from elsewhere.

## Implementation notes
- Keep this mission optional and independent of the main campaign.
- Grant future rewards only once using a persistent completion flag.
- Preserve existing save fields and the current save key.
- Future runtime work should add a map marker, objective chain, journal entry and completion test together.
