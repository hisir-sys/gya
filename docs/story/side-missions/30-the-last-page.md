# Side Mission — The Last Page

- **District:** College Street
- **Lead:** Jax Mercer
- **Theme:** Passing stories forward
- **Status:** Narrative design brief; not yet connected to the playable mission runtime.

## Premise
A retiring bookseller wants to leave a note for the next generation about why the lane matters.

## Mission beats
1. Visit the shop
2. collect memories from neighbouring stalls
3. prepare a farewell reading
4. add the note to the community archive.

## Player choice
Read the note aloud at the shop or place it in the reading room archive.

## Implementation notes
- Keep this mission optional and independent of the main campaign.
- Grant future rewards only once using a persistent completion flag.
- Preserve existing save fields and the current save key.
- Future runtime work should add a map marker, objective chain, journal entry and completion test together.
