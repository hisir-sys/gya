# Side Mission 08 — The Clay Colour Book

- **District:** Kumartuli
- **Lead:** Eli Cross
- **Theme:** Craft heritage
- **Status:** Narrative design brief; not yet connected to the playable mission runtime.

## Premise
An apprentice is building a colour reference for clay finishing and needs help documenting traditional methods.

## Mission beats
1. Visit the workshop
2. record material names
3. photograph sample boards with permission
4. assemble a small reference book.

## Player choice
Credit one master artisan or list all contributors equally.
