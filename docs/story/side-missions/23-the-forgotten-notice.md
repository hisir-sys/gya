# Side Mission — The Forgotten Notice

- **District:** Howrah
- **Lead:** Nia Vale
- **Theme:** Civic memory
- **Status:** Narrative design brief; not yet connected to the playable mission runtime.

## Premise
A community hall's noticeboard still carries outdated information and residents want a better way to maintain it.

## Mission beats
1. Audit the board
2. confirm current public contacts
3. remove expired notices with permission
4. introduce a monthly review date.

## Player choice
Use a volunteer rota or ask the hall to appoint an editor.

## Implementation notes
- Keep this mission optional and independent of the main campaign.
- Grant future rewards only once using a persistent completion flag.
- Preserve existing save fields and the current save key.
- Future runtime work should add a map marker, objective chain, journal entry and completion test together.
