# Neon State

An original, lightweight open-world urban action prototype. It uses original characters, city layout, mission writing, and simple generated graphics; it does not include GTA V code, story, map data, or proprietary assets.

## Run
Open `index.html` in a desktop browser, or run `python -m http.server 8000` here and visit `http://localhost:8000`.

## Controls
- WASD / arrows: move
- E: enter/exit nearby vehicle
- 1 / 2 / 3: switch protagonists
- Space: interact with mission markers
- Shift: sprint

## Current milestone
A playable top-down city prototype with three protagonists, drivable vehicles, a minimap, and a starter mission. This is an early prototype, not a finished 3D game.

## Roadmap
1. Core city and character controls
2. Vehicle handling and world interactions
3. Mission framework, dialogue, and save/load
4. More original locations, NPCs, and story chapters
